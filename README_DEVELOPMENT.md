# Development Snapshot

This ZIP contains the current FactCheckBot repository development snapshot plus the senior-level product specification.

## Important

This is a development snapshot, not a claim that every capability in `MASTER_PRODUCT_SPEC.md` is already implemented.

Current implementation includes the existing FastAPI application, web research/evidence flow, claim decomposition, content modes, Groq integration, history, sharing/report UI, media pipeline, PostgreSQL/SQLite support, Render configuration, tests and CI configuration.

The next engineering work should prioritize the evidence/research engine and provider abstraction before adding large numbers of UI features.
